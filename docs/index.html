CORE CAPABILITIES

为可靠性而生，为轻量而设计

不依赖数据库、不依赖 GUI 框架、不派生任何外部进程——所有能力都装进一个二进制文件。

🍱

统一入口，路径识别

一个地址服务所有助手：127.0.0.1/<agent-id>/v1/…，无需为每个 Agent 单独开端口。OpenAI 兼容协议，任意客户端即插即用。

🔀

自动故障转移

路由组内按优先级依次尝试：滑动窗口熔断、额度软上限、429 被动校准、首 chunk 错误即时切换。上游抖动，Agent 无感。

🔑

多 Key 轮转

同一服务商可挂多个 API Key，请求按轮转分摊；单个 Key 返回 401/403 自动切换下一个重试，全部失败才转移其他服务商。

🖥️

表单化 Web 控制台

五视图中英双语界面：选厂商 → 选套餐 → 贴 Key 即添加服务商；路由组拖拽排序、免费模型标识、配置热重载即时生效，无需手写 YAML。

🔌

接入器一键托管

自动检测本机已安装的 OpenCode / Codex / Hermes，一键改写其本地配置接入网关；配置漂移全自动修复，支持 OpenCode 多实例独立路由。

🔒

加密备份与还原

配置 + 全部 Key 打包经 Argon2id + AES-256-GCM 密码加密导出为 .aback；导入自动校验、自动 .bak 备份并热重载。

QUICK START

三步开饭

从解压到第一个请求，通常不超过一分钟。

01

贴 Key 添加服务商

打开控制台，选厂商、选套餐、粘贴 API Key——模型目录自动拉取，免费模型自动标识。

02

一键接入 Agent

本机已安装的 OpenCode / Codex / Hermes 自动被识别，拨一下开关即完成配置注入，真实 Key 永不落入 Agent 配置。

03

坐等故障转移

429、超时、额度耗尽——网关按路由链自动切换下一候选，并在控制台如实汇报每一次转移轨迹。

terminal
# 解压即用，无安装步骤
$ tar xzf agentbuffet-linux-x86_64.tar.gz && cd agentbuffet-linux-x86_64

# 启动网关（自动载入 ~/.agentbuffet/env 中的密钥）
$ ./AgentBuffet serve
  网关   http://127.0.0.1:3425/<agent-id>/v1/…
  控制台 http://127.0.0.1:3426/

# 检测本机 Agent 并一键接入
$ ./AgentBuffet agents detect
  ✓ opencode   已安装 · 未接入 → attach
$ ./AgentBuffet agents attach opencode
  已写入 ~/.config/opencode/opencode.json（原文件备份 .bak）

# 开机自启：systemd / LaunchAgent / 启动目录，纯文件操作
$ ./AgentBuffet service install
SECURITY BY DESIGN

密钥只属于这台机器

默认全部留在本地，边界清晰、fail-closed。

🏞️

仅监听回环地址

管理面与 UI 只接受 127.0.0.1 访问，非 loopback 请求一律 403；流量端口亦可暴露给局域网由你决定。

🗝️

Key 永不落盘

真实 API Key 只存在于网关进程环境变量；日志、UI、Agent 配置中只有占位符与末四位掩码。

🧱

零外部进程

静态聚合、纯 Rust 实现：不依赖 C 运行库、不派生子进程、不联网上报遥测。

🧾

配置可回滚

接入器改写任何文件前先备份，卸载逐字节还原；配置校验失败拒绝加载，旧快照继续服务。
